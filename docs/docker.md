# Docker Compose вручную

Для установки готового образа и управления обновлениями из браузера используйте [установщик](install.md). Команды ниже собирают исходники на сервере. Нужны Git, Docker Engine и Compose v2.

## Запуск

```bash
git clone https://github.com/godzzdeal/hy2-p.git
cd hy2-p
cp .env.example .env
mkdir -p certs
```

В `.env` замените `PANEL_ADMIN_PASSWORD`, затем выполните:

```bash
docker compose up -d --build
```

Compose запускает веб-интерфейс Next.js и Go-панель. По умолчанию веб-панель опубликована только на `127.0.0.1:8080`, HY2 на `8443/UDP` всех интерфейсов.

Для входа выполните на компьютере, заменив пользователя и адрес:

```bash
ssh -N -L 18080:127.0.0.1:8080 USER@SERVER_IP
```

Откройте `http://127.0.0.1:18080`. Данные первого входа взяты из `.env`.

## Переменные `.env`

- `PANEL_ADMIN_USERNAME`: начальный логин, по умолчанию `admin`.
- `PANEL_ADMIN_PASSWORD`: обязательный начальный пароль; замените значение примера.
- `PANEL_BIND`: адрес публикации Docker, по умолчанию `127.0.0.1`. Для публичного входа задайте `0.0.0.0` или подходящий IPv6-адрес.
- `PANEL_PORT`: TCP-порт панели, по умолчанию `8080`. Публикуется тот же порт контейнера.
- `PANEL_PUBLIC_URL`: адрес для ссылок с протоколом и портом. Например, `https://panel.example.com:9443`.
- `PANEL_SECURE_COOKIE`: `true` для HTTPS за reverse proxy. Встроенный HTTPS сам включает Secure-cookie.
- `PANEL_TLS_MODE`: начальный режим `http`, `tls` или `acme`; по умолчанию `http`. Для своих сертификатов настройте пути и пару через интерфейс.
- `PANEL_DOMAIN`: домен или публичный IP для ACME.
- `PANEL_ACME_EMAIL`: email аккаунта ACME.
- `PANEL_ACME_ACCEPT_TERMS`: принятие условий Let's Encrypt, по умолчанию `false`; для ACME нужно `true`.
- `PANEL_ACME_PORT`: внутренний HTTP-порт проверки, по умолчанию `9080`. Должен совпадать с настройкой панели.
- `HYSTERIA_PUBLIC_PORT`: UDP-порт хоста для основного экземпляра, по умолчанию `8443`.
- `HYSTERIA_LISTEN_PORT`: UDP-порт контейнера из `listen`, по умолчанию `8443`.
- `PANEL_IMAGE`: имя Docker-образа, по умолчанию `hy2-panel:local`.
- `PANEL_CERTS_DIR`: каталог внешних сертификатов на хосте, по умолчанию `./certs`; подключается как `/certs` только для чтения.
- `PANEL_INSTALL_DIR`: метка каталога установки; при ручном запуске оставьте незаданной. Одна эта переменная не подключает помощник управления.

Сохранённые в панели настройки имеют приоритет над начальными переменными. Смена `PANEL_ADMIN_PASSWORD` после первого входа не заменяет пароль, сохранённый в панели.

## Публичный HTTPS

Для первоначального ACME укажите в `.env`:

```dotenv
PANEL_TLS_MODE=acme
PANEL_DOMAIN=panel.example.com
PANEL_ACME_EMAIL=admin@example.com
PANEL_ACME_ACCEPT_TERMS=true
PANEL_PORT=9443
PANEL_BIND=0.0.0.0
PANEL_PUBLIC_URL=https://panel.example.com:9443
PANEL_ACME_PORT=9080
```

Запустите с публикацией HTTP-проверки:

```bash
docker compose -f compose.yaml -f compose.acme.yaml up -d --build
```

Внешний TCP `80` направляется на внутренний порт проверки. Он нужен для выпуска и продления сертификата. Если занят reverse proxy, настройте обработку проверки на нём либо завершайте HTTPS панели на самом прокси.

Для HTTP ACME экземпляров используется тот же `compose.acme.yaml`. TLS-проверке HY2 нужен отдельный проброс TCP `443`, DNS-проверка не требует входящего порта.

## Состояние и остановка

```bash
docker compose ps
docker compose logs --follow --tail 100 panel
docker compose stop
docker compose start
```

`Ctrl+C` завершает просмотр журнала. Остановка Go-панели прерывает все запущенные ею экземпляры HY2. Работавшие экземпляры восстанавливаются при запуске, вручную остановленные не запускаются.

Используйте при следующих операциях тот же набор `-f`, с которым запустили Compose, например с `compose.acme.yaml` для ACME.

## Изменение портов и версии

После изменения порта в интерфейсе согласуйте `PANEL_PORT` и `PANEL_BIND` в `.env`, затем пересоздайте сервисы:

```bash
docker compose up -d --build
```

Для UDP согласуйте `HYSTERIA_PUBLIC_PORT` и `HYSTERIA_LISTEN_PORT` с конфигурацией. Автоматическое применение портов, обновление и откат панели из браузера требуют управляемой установки; одного `compose.yaml` для них недостаточно.

## Данные

Рабочие данные хранятся в томе `panel-data` с префиксом проекта Compose. Панель работает с UID `10001`, её контейнер не получает Docker socket.

Не удаляйте том при пересоздании. Для полной копии остановите панель и сохраните том, `.env` и `certs`. Ключ `secrets/users.key` нужен для чтения зашифрованных паролей пользователей.

`docker compose down` удаляет контейнеры и сеть, сохраняя именованный том. Параметр `--volumes` удалит том с данными. Команды `hy2-panel backup`, `rollback` и `uninstall` относятся к установке скриптом и не обслуживают этот ручной запуск.
