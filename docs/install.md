# Установка HY2 Control

## 1. Подготовьте сервер

Нужен VPS с Ubuntu 22.04, 24.04, 26.04 или 26.10 и публичным IP. Архитектура: amd64 или arm64.

Откройте терминал или консоль в личном кабинете хостинга. При входе по SSH команда обычно выглядит так:

```bash
ssh root@IP_СЕРВЕРА
```

Вместо `IP_СЕРВЕРА` укажите адрес из личного кабинета хостинга. Если входите другим пользователем, для установки понадобятся права sudo.

## 2. Подготовьте адрес и порты

Для HTTPS нужен домен или поддомен. Создайте для него DNS-запись типа **A**, которая указывает на публичный IPv4 сервера.

Проверьте запись на своём компьютере:

```bash
nslookup panel.example.com
```

Замените `panel.example.com` своим адресом. В ответе должен быть IP вашего сервера.

В firewall хостинга и сервера разрешите:

- **TCP 9443**: вход в веб-панель.
- **TCP 80**: выпуск и продление сертификатов через HTTP.
- **UDP 8443**: подключение к Hysteria2 по умолчанию.

Если выберете другие порты, разрешите именно их. TCP и UDP являются разными правилами.

## 3. Запустите установщик

Выполните на сервере:

```bash
curl -fsSL https://github.com/godzzdeal/hy2-p/releases/latest/download/install.sh -o /tmp/hy2-install.sh
sudo bash /tmp/hy2-install.sh
```

Ответьте на вопросы мастера:

1. **Домен панели**: только имя, например `panel.example.com`, без `https://`, порта и пути.
2. **Логин**: Enter оставит `admin`.
3. **Email**: адрес для сертификата Let's Encrypt.
4. **Условия центра сертификации**: введите `yes`, если принимаете их.

Пароль создаётся автоматически. Установщик скачает готовый образ и запустит панель. При первом обращении по HTTPS начнётся выпуск сертификата.

В конце появится адрес, например `https://panel.example.com:9443`, логин и пароль. Сохраните их.

Если домена нет, на первом вопросе нажмите Enter. Установщик покажет команду SSH-туннеля. Запустите её на своём компьютере и используйте указанный локальный адрес.

## 4. Настройте VPN

Установка панели ещё не означает, что VPN настроен.

1. Войдите в панель.
2. В **Конфигурации** задайте публичный адрес и UDP-порт. Включите **SNI совпадает с адресом**, если сертификат выдан на этот адрес.
3. Откройте **TLS / ACME**. Выберите свой сертификат с ключом либо ACME.
4. Для ACME укажите свой домен и email. HTTP-проверке нужен доступный снаружи TCP 80.
5. В **Authentication** оставьте **Пользователи панели**, чтобы управлять доступом через интерфейс.
6. Сохраните конфигурацию и запустите ядро.
7. В **Ядро и журнал** проверьте, что сервер запущен без ошибок сертификата.

Сертификат веб-панели и сертификат Hysteria2 независимы. Если HTTPS панели работает, ядру всё равно нужен свой TLS или ACME.

## 5. Добавьте телефон или компьютер

1. Установите Happ на устройстве.
2. В панели откройте **Пользователи → Добавить пользователя**.
3. Введите имя. Флаг выбирается отдельно, обычные эмодзи можно добавить в имя.
4. Сохраните пользователя и откройте его подключение.
5. Импортируйте подписку в Happ либо отсканируйте QR-код.
6. Подключитесь и проверьте открытие сайта.

Подписка позволяет приложению получать последующие изменения. Если добавили только отдельную ссылку, её параметры не обновятся через подписку.

## Установка без вопросов

Сначала скачайте установщик командой из шага 3. Затем используйте свои домен и email:

```bash
sudo bash /tmp/hy2-install.sh --yes --domain panel.example.com --email admin@example.com --accept-acme-terms
```

Флаг `--accept-acme-terms` означает принятие условий Let's Encrypt.

## Где данные входа

Адрес можно повторно вывести командой:

```bash
sudo hy2-panel url
```

Начальные логин и пароль записаны в `/opt/hy2-panel/.env`. После изменения пароля в интерфейсе начальное значение в файле уже не является текущим паролем.
