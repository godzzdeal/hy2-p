# Установка HY2-P

## 1. Подготовьте сервер

Нужен VPS с публичным IP и Ubuntu 22.04, 24.04, 26.04 или 26.10. Поддерживаются amd64 и arm64. Docker устанавливается автоматически, панель загружается готовым образом.

Подключитесь к серверу через SSH или консоль хостинга:

```bash
ssh root@IP_СЕРВЕРА
```

В firewall сервера и хостинга разрешите:

- **TCP 9443** для панели по HTTPS или **TCP 8080** для HTTP.
- **UDP 8443** для подключения к HY2 по умолчанию.
- **TCP 80** для выпуска и продления сертификатов ACME через HTTP.

Если выберете другие порты, разрешите их. TCP и UDP настраиваются отдельно. Для доступа только через SSH открывать порт панели снаружи не нужно.

## 2. Подготовьте адрес

Можно использовать домен или публичный IP. Для домена нужна DNS-запись **A** с IPv4 вашего сервера. Если добавляете **AAAA**, IPv6 тоже должен вести на этот сервер.

Проверьте адрес:

```bash
nslookup panel.example.com
```

В ответе должен быть IP вашего VPS. При установке по IP проверка DNS не нужна.

### Бесплатный домен FreeDNS

[FreeDNS](https://freedns.afraid.org/) | [Регистрация](https://freedns.afraid.org/signup/) | [Каталог доменов](https://freedns.afraid.org/domain/registry/)

1. Зарегистрируйтесь, подтвердите email и войдите.
2. В **Registry** выберите публичный домен, например `mooo.com`, если он доступен.
3. Создайте запись **Type: A**. В **Subdomain** укажите свободное имя, в **Destination** укажите IPv4 вашего VPS. Сайт может подставить IP вашего компьютера: замените его.
4. Нажмите **Save**. Получится адрес вида `my-vpn.mooo.com`.
5. Проверьте его через два DNS-сервера:

```bash
nslookup my-vpn.mooo.com 1.1.1.1
nslookup my-vpn.mooo.com 8.8.8.8
```

Оба ответа должны содержать IP VPS. В начале вывода указан адрес DNS-сервера, который отвечает на запрос.

Пример успешного ответа:

```text
Server:         1.1.1.1
Address:        1.1.1.1#53

Non-authoritative answer:
Name:   my-vpn.mooo.com
Address: 203.0.113.10
```

Проверьте **Address под именем `my-vpn.mooo.com`**: там должен быть IP вашего VPS. `203.0.113.10` указан для примера. Ответ через `8.8.8.8` должен содержать тот же IP. Надпись `Non-authoritative answer` означает ответ публичного DNS-сервера и не является ошибкой.

Изменения могут появиться не сразу из-за кеширования DNS. У FreeDNS TTL по умолчанию составляет 1 час. Если видите старый IP или `NXDOMAIN`, подождите и повторите проверку. При длительной задержке проверьте имя, тип **A** и **Destination**.

Выпускайте сертификат после того, как домен начнёт указывать на сервер. При смене IP обновите **Destination** в **Subdomains**; для автоматического обновления есть **Dynamic DNS**.

[Руководство FreeDNS](https://freedns.afraid.org/guide/dd-wrt/) | [Вопросы о DNS и кеше](https://freedns.afraid.org/faq/)

## 3. Установка

Скачайте установщик:

```bash
curl -fsSL https://hy2-p.vercel.app/install.sh -o /tmp/hy2-install.sh
```

Выберите один вариант запуска. Замените адрес и email своими значениями.

### С выбором настроек

```bash
sudo bash /tmp/hy2-install.sh
```

Введите домен или публичный IP и выберите HTTPS либо HTTP. Пустой адрес оставит доступ через SSH-туннель. Подтверждения принимают `yes/no` и `y/n`.

### HTTPS по домену

```bash
sudo bash /tmp/hy2-install.sh --yes --domain panel.example.com --email admin@example.com --accept-acme-terms
```

### HTTPS по публичному IP

```bash
sudo bash /tmp/hy2-install.sh --yes --address IP_СЕРВЕРА --email admin@example.com --accept-acme-terms
```

Let's Encrypt выдаёт IP-сертификат на 160 часов. Панель продлевает его автоматически; входящий TCP 80 должен оставаться доступным. Приватные адреса для такого сертификата не подходят.

### HTTP по публичному IP

```bash
sudo bash /tmp/hy2-install.sh --yes --address IP_СЕРВЕРА --http
```

Домен и сертификат не нужны. HTTP-соединение не шифруется.

Параметр `--port` меняет порт панели. `--accept-acme-terms` подтверждает принятие условий Let's Encrypt.

Необязательный `--open-ports` добавляет базовые правила UFW для выбранных настроек. Состояние UFW не меняется; firewall хостинга настраивается отдельно. Без параметра правила не изменяются.

Установщик покажет адрес панели, логин и созданный пароль. Сохраните их. Для режима SSH он также покажет команду туннеля, которую нужно выполнить на своём компьютере.

## 4. Настройте HY2

1. Откройте панель и перейдите в **Конфигурацию**.
2. Проверьте публичный адрес, UDP-порт и SNI. При первоначальной настройке общий домен подставляется автоматически; адрес панели и адрес экземпляра можно изменить отдельно.
3. В **TLS / ACME** выберите свой сертификат с ключом либо автоматический ACME. Для домена адрес и email подставляются из настроек. TCP 80 нужен для HTTP-проверки сертификата.
4. В **Authentication** оставьте **Пользователи панели**, чтобы управлять доступом через интерфейс.
5. Сохраните конфигурацию. В **Управлении HY2** запустите экземпляр и проверьте журнал.

Сертификаты панели и HY2 настраиваются отдельно. Сертификат панели на IP не заменяет сертификат VPN. Новый экземпляр можно создать в **Экземплярах** с отдельным конфигом и UDP-портом.

## 5. Добавьте пользователей

1. В **Пользователях** нажмите **Добавить**.
2. Укажите имя. Пароль можно создать автоматически. При желании задайте срок доступа и флаг.
3. Сохраните пользователя и откройте **Подключение**.
4. Импортируйте подписку по ссылке или QR-коду в приложение с поддержкой Hysteria2 и проверьте подключение.

Подписка получает изменения при обновлении в приложении. Отдельная ссылка подключения автоматически не обновляется. Общий флаг пользователей задаётся в **Подписках**; индивидуальный флаг имеет приоритет.
