# Переменные установщика

Для обычной установки используйте [параметры командной строки](parameters.md). Переменные нужны для автоматизации и сборки из исходников. Задайте их перед запуском скрипта установки.

Если заданы и аргумент, и переменная окружения, используется аргумент. Передавайте переменные уже под `root` либо через `sudo env`; обычный `sudo` может удалить их из окружения.

## `HY2_INSTALL_DIR`

Каталог установки. По умолчанию `/opt/hy2-panel`. Эквивалент `--directory`. После установки созданная команда `hy2-panel` сама выбирает этот каталог.

## `HY2_NONINTERACTIVE`

`true` отключает вопросы, как `--yes`. По умолчанию `false`. HTTPS всё равно требует адрес, email и принятие условий ACME.

## `HY2_DOMAIN`

Домен или публичный IP панели. Эквивалент `--domain` и `--address`. Без значения адрес запрашивается у пользователя; с отключёнными вопросами выбирается доступ через SSH.

## `HY2_EMAIL`

Email для ACME. Эквивалент `--email`. Не имеет начального значения.

## `HY2_PORT`

TCP-порт панели. Эквивалент `--port`. Без значения выбирается `9443` для публичного HTTPS или `8080` для HTTP и SSH.

## `HY2_USERNAME`

Начальный логин, по умолчанию `admin`. Эквивалент `--username`.

## `HY2_ADMIN_PASSWORD`

Начальный пароль администратора. Если переменная не задана, скрипт создаёт пароль из 48 шестнадцатеричных символов. Свой пароль должен содержать от 16 до 72 ASCII-символов: латинские буквы, цифры или `_ @ % + = : . , / -`. Пробелы, кавычки и `#` не принимаются.

Не записывайте реальный пароль в общедоступный скрипт или пример команды. Установщик сохраняет начальные данные в `.env` с доступом только для root. После первого запуска изменение `.env` не сбрасывает пароль входа. Меняйте его в панели или командой `password-reset`.

## `HY2_ACCEPT_ACME_TERMS`

`true` подтверждает условия ACME, как `--accept-acme-terms`. По умолчанию `false`.

## `HY2_HTTP`

`true` выбирает публичный HTTP, как `--http`. По умолчанию `false`. Без адреса используйте SSH-доступ, а не `--http`.

## `HY2_OPEN_PORTS`

`true` добавляет правила UFW, как `--open-ports`. По умолчанию `false`. Службу UFW не включает.

## `HY2_BUILD_FROM_SOURCE`

`true` собирает Docker-образ из исходников вместо загрузки готового релизного архива. По умолчанию `false`. Для сборки нужны свободные память и место на диске. Время зависит от мощности сервера и скорости сети.

Для установки ветки `main` под `root`:

```bash
export HY2_BUILD_FROM_SOURCE=true
bash <(curl -fsSL https://hy2-p.vercel.app/install.sh) --version main
unset HY2_BUILD_FROM_SOURCE
```

Для обновления существующей установки:

```bash
sudo env HY2_BUILD_FROM_SOURCE=true hy2-panel update main
```

Флага `--build-from-source` нет. Переменной для выбора версии тоже нет: передавайте `--version` при установке или версию после `hy2-panel update`.

## Настройки после установки

`.env` задаёт начальные параметры. Сохранённые в панели настройки имеют приоритет. Меняйте логин, порт, домен и HTTPS в **Настройках**, а публичный UDP-порт в **Конфигурации** выбранного экземпляра.

Переменные `PANEL_*` и `HYSTERIA_*` ручного Docker Compose описаны в [инструкции Docker](../docker.md). Служебные токены проверки портов не задавайте вручную.
