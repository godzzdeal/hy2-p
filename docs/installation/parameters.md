# Параметры установщика

[Установка](../install.md) | [Переменные окружения](environment.md) | [Ошибки установки](troubleshooting.md)

Запускайте команды на сервере под `root`. Войдя под другим пользователем, сначала выполните `sudo -i`.

```bash
bash <(curl -fsSL https://hy2-p.vercel.app/install.sh) --help
```

Параметры передаются после `bash <(...)`.

## Адрес и HTTPS

### `--domain АДРЕС` и `--address АДРЕС`

Два имени одного параметра. Принимают домен, IPv4 или IPv6 без схемы, порта и пути: `panel.example.com`, `203.0.113.10` или `2001:db8::10`. Если указать оба параметра, используется последний.

При заданном адресе по умолчанию включается HTTPS с ACME. Для HTTP добавьте `--http`. Без адреса мастер спросит его; пустой ответ оставляет HTTP на `127.0.0.1`, доступный через SSH-туннель. С `--yes` и без адреса этот режим выбирается сразу.

### `--email EMAIL`

Email аккаунта ACME, например `admin@example.com`. Обязателен для автоматического HTTPS. При пошаговой установке мастер спросит его, если он не задан. Для HTTP не требуется.

### `--accept-acme-terms`

Подтверждает принятие [условий Let's Encrypt](https://letsencrypt.org/repository/). При пошаговой настройке их можно принять в ответ на вопрос. Для HTTPS с `--yes` параметр обязателен.

### `--http`

Публикует веб-панель по HTTP. Требует `--domain` или `--address`. Сертификат не выпускается, соединение не шифруется. По умолчанию используется TCP `8080`.

### `--port ПОРТ`

TCP-порт веб-панели. По умолчанию `9443` для публичного HTTPS и `8080` для HTTP или SSH-доступа. Допустимы числа от `1024` до `65535`, кроме `8081`, `9080`, `9090–9097` и `9999–10006`: они заняты внутренними службами.

Этот параметр не меняет UDP-порт HY2. Его начальное значение `8443`; после установки порт меняется в **Конфигурации** экземпляра.

### `--open-ports`

Добавляет правила UFW для TCP-порта панели, UDP-порта HY2 и TCP `80`, если включён ACME. Не включает UFW и не устанавливает его. Если UFW отсутствует, выводит сообщение и продолжает установку. Без этого параметра правила не меняются.

Firewall хостинга настраивается отдельно. Публикация порта Docker и разрешение в UFW не заменяют друг друга. [Подробнее о портах](../management/firewall.md).

## Учётная запись

### `--username ЛОГИН`

Начальный логин администратора. По умолчанию `admin`. Допускаются от 3 до 64 латинских букв, цифр и символов `_`, `.` и `-`. При пошаговой установке мастер предложит заданное значение и даст его изменить.

Пароль создаётся случайно и выводится после успешной установки. Флага `--password` нет. Для автоматизации пароль можно передать через `HY2_ADMIN_PASSWORD`; [требования к нему](environment.md#hy2_admin_password).

### `--yes`

Пропускает вопросы мастера. Не принимает условия ACME вместо `--accept-acme-terms` и не открывает порты вместо `--open-ports`. Все обязательные значения должны быть заданы заранее.

## Версия и каталог

### `--version ВЕРСИЯ`

По умолчанию `latest`, последний релиз GitHub. Можно указать точный тег вида `v0.9.2`, `main` или полный 40-символьный хеш коммита. Короткий хеш и номер без `v` не принимаются текущим скриптом.

Готовые образы загружаются для релизных тегов. Для `main` и коммита без готового образа нужна сборка на сервере с `HY2_BUILD_FROM_SOURCE=true`. [Пример](environment.md#hy2_build_from_source).

### `--directory ПУТЬ`

Каталог установки, по умолчанию `/opt/hy2-panel`. Укажите отдельный абсолютный путь без пробелов, `..` и символических ссылок. Нельзя использовать `/`, `/opt` или `/tmp` целиком.

Здесь хранятся исходники версий, сертификаты панели, копии и архивы отката. Рабочие данные находятся в Docker-томе. Несколько независимых установок этим параметром не поддерживаются.

### `--help` и `-h`

Печатают краткую справку и завершают работу без установки.

## Примеры

HTTPS по домену на TCP `10443`, с логином `operator` и правилами UFW:

```bash
bash <(curl -fsSL https://hy2-p.vercel.app/install.sh) \
  --yes --domain panel.example.com --email admin@example.com \
  --port 10443 --username operator --accept-acme-terms --open-ports
```

HTTP по IP без изменения правил firewall:

```bash
bash <(curl -fsSL https://hy2-p.vercel.app/install.sh) \
  --yes --address 203.0.113.10 --http
```

Установка определённого релиза в другой каталог:

```bash
bash <(curl -fsSL https://hy2-p.vercel.app/install.sh) \
  --version v0.9.2 --directory /opt/hy2-p --yes
```

Последний пример оставляет доступ через SSH. Если в выбранном каталоге уже есть установка, скрипт запускает её обновление. Переданные адрес, логин и порт при этом не заменяют сохранённые настройки.
