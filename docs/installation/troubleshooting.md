# Ошибки установки

## Домен ведёт на другой адрес

```bash
nslookup panel.example.com 1.1.1.1
nslookup panel.example.com 8.8.8.8
```

В блоке ответа для домена должен быть публичный IP VPS. Если есть запись AAAA, она тоже должна вести на этот сервер. Исправьте записи у DNS-провайдера и дождитесь обновления кеша. [FreeDNS и пример ответа](../install.md#бесплатный-домен-freedns).

## ACME возвращает 404 или Connection refused

Для HTTP-проверки Let's Encrypt нужен входящий TCP `80`. Проверьте правила firewall сервера и хостинга, затем посмотрите, какая служба слушает порт:

```bash
sudo ss -ltnp '( sport = :80 or sport = :443 )'
sudo docker ps --format 'table {{.Names}}\t{{.Ports}}'
```

`404` по пути `/.well-known/acme-challenge/` часто означает, что запрос попал в другой веб-сервер. `Connection refused` означает отказ соединения. HTTPS панели на `9443` не заменяет TCP `80` для HTTP-проверки.

В управляемой установке токены ACME панели и экземпляров обслуживает общий шлюз. После первого включения ACME экземпляра примените публикацию TCP `80` перезапуском панели. Если порт занят своим reverse proxy, настройте маршрутизацию проверки или используйте другой способ выпуска сертификата.

## Панель недоступна

```bash
sudo hy2-panel status
sudo hy2-panel url
sudo hy2-panel logs
```

Откройте адрес из `url`, включая порт. Для SSH-режима выполните показанную команду туннеля на компьютере. Для публичного адреса проверьте TCP-порт панели в firewall хостинга.

Если установщик завершился до создания команды `hy2-panel`, исправьте указанную ошибку и повторите установку с тем же `--directory`. Он сохраняет `.env` и данные неудачного первого запуска.

## VPN подключается, но сайты не открываются

Сначала сравните публичный UDP-порт, публикацию Docker и `listen`. Затем откройте журнал нужного экземпляра в **Управление HY2**. Проверяйте тем же профилем через разные сети: доступность панели по TCP ещё не подтверждает доступность VPN по UDP.

Если подписка не обновляется только при включённом VPN, выключите его и повторите обновление. Если без VPN подписка обновляется, проверьте само VPN-подключение.

## Нет готового образа

Для `main` и произвольного коммита готового релизного архива может не быть. Выберите релизный тег или явно включите [сборку из исходников](environment.md#hy2_build_from_source). Если архив не прошёл проверку контрольной суммы, скрипт его не устанавливает.

## Docker установлен, но установка остановилась

```bash
sudo docker info
sudo docker compose version
```

Нужны работающий локальный Docker и Compose v2. Скрипт не удаляет существующий Docker или containerd для замены другим пакетом. Восстановите работу Docker и Compose, затем повторите установку.

## Другая операция уже выполняется

Дождитесь обновления, отката, резервного копирования или смены порта. Не удаляйте файлы блокировки и `*.pending`: они нужны для восстановления прерванных операций. Если процесс завершился с ошибкой, сохраните вывод и проверьте журнал панели.
