# Обновление, копии и восстановление

Команды выполняются на сервере, где установлена панель.

## Узнать адрес и состояние

```bash
sudo hy2-panel url
sudo hy2-panel status
```

`url` показывает адрес панели или команду SSH-туннеля. `status` показывает состояние контейнеров и установленный коммит.

## Обновить панель

```bash
sudo hy2-panel update
```

Сервер скачает готовый образ своей архитектуры, проверит его и создаст резервную копию перед переключением. Во время скачивания старая панель продолжает работать. Во время переключения будет короткий перерыв.

Если новая версия не проходит проверку запуска, менеджер пробует вернуть предыдущую версию и её данные. Не закрывайте терминал, пока команда не закончилась.

Для конкретного релиза используйте его настоящий номер из списка версий:

```bash
sudo hy2-panel update v0.4.0
```

Если у вас v0.1.3 или старше, повторно запустите новый установщик из [инструкции](install.md). Старый менеджер ещё собирал проект на сервере.

## Обновить Hysteria2

Откройте **Ядро и журнал** в панели, выберите версию ядра и запустите обновление.

Это отдельная операция: `hy2-panel update` обновляет панель, а кнопка в интерфейсе обновляет Hysteria2.

Watchdog контролирует ядро, которое должно работать. Если после обновления оно падает, панель пробует перезапуск, затем откат. Ручная остановка ядра сохраняется и не считается сбоем.

## Сделать резервную копию

```bash
sudo hy2-panel backup
```

Команда показывает каталог созданной копии. По умолчанию копии находятся внутри `/opt/hy2-panel/backups`.

Копия содержит настройки, базу, ключи и сертификаты, которые обслуживает установка. Храните её в приватном месте; для защиты от потери всего VPS скопируйте её за пределы сервера.

## Откатить панель

```bash
sudo hy2-panel rollback
```

Команда запросит подтверждение и вернёт предыдущую версию вместе с данными из копии перед обновлением. Новые пользователи и изменения, сделанные после той копии, не войдут в восстановленное состояние.

Перед откатом сохраняется отдельная копия текущего состояния. Не удаляйте копии и файлы незавершённой операции вручную, если восстановление ещё не завершилось.

## Перезапустить панель

```bash
sudo hy2-panel restart
```

После смены домена или порта используйте адрес, который покажет команда.

Изменение порта веб-панели и применение UDP-порта Hysteria2 являются разными операциями. Для UDP используйте **Применить UDP-порт** в конфигурации.

## Посмотреть журнал панели

```bash
sudo hy2-panel logs
```

Нажмите Ctrl+C, чтобы выйти из просмотра. Это не остановит сервер.

Журнал самой Hysteria2 находится в **Ядро и журнал** в браузере.

## Остановить и запустить

```bash
sudo hy2-panel stop
sudo hy2-panel start
```

Остановка панели прерывает работу управляемого ею ядра.

## Правила firewall

В **Настройки → Firewall сервера** показаны нужные порты по конфигурациям панели и ядер. Там же можно скопировать готовую команду. Например, открыть UDP-порт `61254`:

```bash
sudo ufw insert 1 allow 61254/udp
```

Для TCP используется `/tcp`. Сохраните доступ к своему SSH-порту и порту панели. Изменения UFW не меняют firewall хостинга и публикацию Docker.

Если закрыли нужный порт, верните действие **Открыть порт** в панели или выполните его команду по SSH. Чтобы удалить добавленное правило, сначала найдите его номер:

```bash
sudo ufw status numbered
sudo ufw delete НОМЕР_ПРАВИЛА
```

Номер берите из текущего списка. После каждого удаления номера остальных правил меняются. Удаление правила не восстанавливает ранее заменённые правила; `ufw reset` для отката не нужен.

## Забыли пароль администратора

Выполните через SSH на сервере:

```bash
sudo hy2-panel password-reset
```

Команда создаст случайный пароль и покажет его вместе с сохранённым логином. Сохраните пароль. Сеансы панели завершатся, подключения VPN кратковременно прервутся при перезапуске. Пользователи и конфигурации сохранятся.

Облачный пароль останется прежним. Его сброс описан ниже.

## Облачный пароль

В **Настройки → Облачный пароль** можно включить дополнительный пароль для входа. Он запрашивается после основного пароля. Для смены или отключения нужны основной и текущий облачный пароли. После сохранения все сеансы завершатся.

Если облачный пароль забыт, владелец сервера может сбросить его через SSH:

```bash
sudo hy2-panel cloud-password-reset
```

Сброс не меняет основной пароль, пользователей и настройки VPN. Команда перезапускает панель и управляемые ядра, поэтому подключения кратковременно прервутся.

## Файлы установки

- `/opt/hy2-panel/.env`: начальные параметры и данные первого входа.
- `/opt/hy2-panel/current`: коммит установленной версии.
- Docker-том `hy2-panel_panel-data`: рабочие настройки, пользователи, сертификаты и счётчики.
- `/opt/hy2-panel/backups`: резервные копии.

Если при установке выбрали другой каталог, используйте его вместо `/opt/hy2-panel`.
