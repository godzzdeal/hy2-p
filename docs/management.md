## Справка команды

```bash
sudo hy2-panel help
```

`-h` и `--help` выводят ту же справку. Команды `hy2-panel` требуют root; в примерах используется `sudo`.

## Состояние

```bash
sudo hy2-panel status
```

Показывает состояние контейнеров Docker Compose и строку `Commit` с коммитом установленной панели. Версия HY2 у каждого экземпляра своя; смотрите её в **Управление HY2**.

## Адрес панели

```bash
sudo hy2-panel url
```

Для публичной установки выводит URL. Для доступа только с сервера выводит команду SSH-туннеля. Выполните её на своём компьютере, оставьте терминал открытым и перейдите по указанному локальному адресу.

## Запуск и остановка

Запустить панель и необходимые ей службы:

```bash
sudo hy2-panel start
```

Остановить панель:

```bash
sudo hy2-panel stop
```

Перезапустить панель и проверить запуск:

```bash
sudo hy2-panel restart
```

Остановка панели завершает все запущенные ею процессы HY2 и VPN-подключения. При следующем запуске восстанавливаются экземпляры, которые работали до остановки. Экземпляры, остановленные вручную, остаются остановленными.

`start` и `restart` также публикуют сохранённый порт веб-панели в Docker и выводят адрес входа. Настройки отдельных экземпляров меняйте в **Конфигурации**; для запуска и перезапуска выбранного экземпляра откройте **Управление HY2**.

### Только контейнер панели

```bash
sudo hy2-panel start-panel
sudo hy2-panel restart-panel
```

`start-panel` запускает или пересоздаёт только сервис `panel`, `restart-panel` сначала останавливает его. Зависимые сервисы не запускаются. Эти команды использует помощник обслуживания; для обычного запуска используйте `start` или `restart`. VPN-подключения при перезапуске `panel` тоже прерываются.

## Журнал панели

```bash
sudo hy2-panel logs
```

Показывает последние 100 строк сервиса `panel`, затем новые записи. `Ctrl+C` завершает просмотр, панель продолжает работать. Параметры `--tail` и `--since` эта команда не поддерживает.

Для однократной выгрузки 200 строк используйте Docker. Имя контейнера сначала проверьте в `status`:

```bash
sudo docker logs --tail 200 hy2-panel-panel-1
```

Это журнал самой панели. Записи процессов HY2 находятся в **Управление HY2 → Журнал экземпляра**. Там доступны поиск, фильтр уровня и отбор по пользователю, скачивание и очистка.

## Другой каталог установки

Установщик создаёт `/usr/local/bin/hy2-panel`, связанный с выбранным каталогом. После установки с `--directory` обычные команды работают без дополнительных параметров. Указывайте свой путь вместо `/opt/hy2-panel` в командах чтения файлов.

`--directory` меняет расположение одной установки. Он не создаёт несколько независимых панелей: имя Compose-проекта, том и команда управления общие.

## Служебные команды портов

`apply-udp`, `remove-udp` и `recover-udp` вызываются помощником панели. Они требуют идентификатора операции, сохранённых метаданных и, для применения порта, токена проверки. Это не команды ручной настройки firewall. Их аргументы и коды завершения описаны в [справке портов](management/firewall.md#служебные-команды).
