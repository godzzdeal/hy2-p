# Команды сервера

Выполняйте команды на сервере через SSH. Если установили панель не в `/opt/hy2-panel`, используйте свой каталог в путях к файлам.

## Адрес и состояние

```bash
sudo hy2-panel url
sudo hy2-panel status
```

`url` показывает адрес панели или команду SSH-туннеля. `status` показывает контейнеры и установленный коммит.

## Обновление панели

```bash
sudo hy2-panel update
```

Менеджер скачает готовый образ, проверит его, создаст резервную копию и переключит контейнер. До переключения панель продолжает работать. Если новая версия не запускается, менеджер вернёт предыдущую версию и её данные. Дождитесь завершения команды.

Для конкретной версии укажите её git-тег, например:

```bash
sudo hy2-panel update v0.7.5
```

Установки v0.1.3 и старше обновляйте повторным запуском [нового установщика](install.md). Обновление экземпляров HY2 выполняется отдельно в разделе **Управление HY2**.

## Резервная копия и откат

```bash
sudo hy2-panel backup
sudo hy2-panel rollback
```

`backup` покажет каталог копии. Она содержит базу, настройки, ключи и сертификаты. Скопируйте её за пределы VPS.

`rollback` запросит подтверждение и вернёт предыдущую версию вместе с данными из копии перед обновлением. Более поздние изменения в неё не входят. Перед откатом также сохраняется текущая копия.

## Запуск и остановка

```bash
sudo hy2-panel start
sudo hy2-panel stop
sudo hy2-panel restart
```

Остановка и перезапуск панели прерывают подключения всех управляемых экземпляров. После смены порта или домена используйте адрес из вывода команды.

Порт веб-панели и UDP-порт HY2 настраиваются отдельно. Для UDP используйте **Применить UDP-порт** в конфигурации экземпляра.

## Журнал панели

```bash
sudo hy2-panel logs
```

Для выхода нажмите `Ctrl+C`. Журнал HY2 находится в **Управлении HY2** в браузере.

## Перенос настроек и пользователей

```bash
sudo hy2-panel export /root/hy2-p.json
sudo hy2-panel import /root/hy2-p.json
sudo hy2-panel import /root/hy2-p.json --apply
```

Без `--apply` импорт показывает предварительный просмотр и совпадения. Существующие записи не перезаписываются. В файле есть пароли и ссылки подписок; сертификаты, зарегистрированные устройства и данные входа в панель не переносятся.

Чтобы исключить экземпляр, укажите его ID из предварительного просмотра:

```bash
sudo hy2-panel import /root/hy2-p.json --skip-core ID_ЭКЗЕМПЛЯРА --apply
```

Чтобы связать импортируемый основной экземпляр с уже существующим:

```bash
sudo hy2-panel import /root/hy2-p.json --map-core default=default --apply
```

## Firewall

```bash
sudo hy2-panel firewall-setup
sudo ufw status numbered
sudo ufw allow 61254/udp
```

Помощник подключает раздел **Настройки → Firewall** и не включает UFW. Для открытия другого порта замените `61254` и протокол. Firewall хостинга настраивается отдельно; опубликованные порты Docker могут обходить UFW.

Для удаления правила сначала посмотрите его номер:

```bash
sudo ufw status numbered
sudo ufw delete НОМЕР_ПРАВИЛА
```

После удаления номера меняются. Не используйте `ufw reset` для отмены одного правила.

## Сброс пароля администратора

```bash
sudo hy2-panel password-reset
```

Команда создаст новый пароль и покажет его с сохранённым логином. Облачный пароль, пользователи и конфигурации сохранятся. Сеансы завершатся; панель и экземпляры кратковременно перезапустятся.

## Сброс облачного пароля

```bash
sudo hy2-panel cloud-password-reset
```

Команда отключит облачный пароль. Основной пароль и настройки сохранятся; панель и экземпляры перезапустятся.

## Файлы установки

- `/opt/hy2-panel/.env`: начальные параметры и данные первого входа.
- `/opt/hy2-panel/current`: коммит установленной версии.
- Docker-том `hy2-panel_panel-data`: рабочие данные панели.
- `/opt/hy2-panel/backups`: резервные копии.
