# Пароли и восстановление доступа

## Забыли основной пароль

```bash
sudo hy2-panel password-reset
```

Команда не принимает аргументы. Она останавливает панель, создаёт новый случайный пароль, сохраняет его, запускает панель и выводит логин с новым паролем. Все действующие сеансы завершаются. Логин сохраняется.

Облачный пароль не сбрасывается. Если он тоже забыт, выполните следующую команду отдельно. Перезапуск прерывает VPN-подключения всех экземпляров; данные пользователей и их пароли не меняются.

Если новый пароль выведен, но проверка запуска не прошла, пароль уже изменён. Не ищите прежний в `.env`: проверьте состояние и журнал панели.

## Забыли облачный пароль

```bash
sudo hy2-panel cloud-password-reset
```

Команда не принимает аргументы. Она отключает дополнительный пароль входа и перезапускает панель. После этого вход выполняется с основным паролем. Основной пароль, пользователи VPN и конфигурации сохраняются.

## Изменить пароль из браузера

В **Настройки → Учётная запись администратора** укажите текущий пароль и новые данные, затем нажмите **Изменить**. Без изменений кнопка недоступна. После смены данных потребуется новый вход.

В **Настройки → Облачный пароль** можно включить, заменить или отключить второй пароль. Это дополнительный этап входа в HY2-P, а не пароль VPN-пользователей и не синхронизация с облачным сервисом.

## Панель не запускается

```bash
sudo hy2-panel status
sudo hy2-panel logs
```

Если контейнер остановлен и не попал в вывод `status`, посмотрите все контейнеры установки:

```bash
sudo docker ps -a --filter label=com.docker.compose.project=hy2-panel
```

Затем прочитайте журнал нужного контейнера. Для стандартного имени:

```bash
sudo docker logs --tail 200 hy2-panel-panel-1
```

После исправления причины запустите панель:

```bash
sudo hy2-panel start
```

## Ошибка обновления

Если обновление завершилось автоматическим откатом, проверьте версию и доступность. Если менеджер сообщает о неудачном восстановлении, сохраните журнал и копии. Не удаляйте `update.pending`, `previous`, `rollback-backup` и архивы: они нужны для возврата согласованного состояния.

Для просмотра журнала завершённого обслуживания найдите имя контейнера:

```bash
sudo docker ps -a --filter name=hy2-panel-maintenance
```

Подставьте найденное имя:

```bash
sudo docker logs --tail 150 ИМЯ_КОНТЕЙНЕРА
```

После автоматической очистки контейнера последние строки могут находиться в `/opt/hy2-panel/last-maintenance.log`. Не публикуйте `.env`, ключи и полные адреса подписок вместе с диагностикой.
