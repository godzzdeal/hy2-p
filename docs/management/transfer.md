# Импорт и экспорт

JSON HY2-P переносит конфигурации экземпляров, пользователей, группы, правила доступа, лимиты и сохранённые счётчики трафика. Формат файла `hy2-p/1`, максимальный размер 16 МБ, до 10 000 пользователей.

В экспорт входят пароли и токены подписок. Сертификаты, приватные файлы ECH, загруженные ACL-базы, зарегистрированные устройства и данные входа в панель отдельно не переносятся. Пути к файлам остаются в конфигурациях; на новом сервере эти файлы нужно подготовить заново.

Панель должна работать: команды обращаются к её внутреннему API. Основной пароль администратора вводить не требуется, доступ проверяется служебным ключом установки.

## Экспорт

```bash
sudo hy2-panel export /root/hy2-p.json
```

`export` принимает один аргумент: путь нового файла. Родительский каталог должен существовать. Существующий файл не перезаписывается; выберите другое имя. Экспорт создаётся с правами `600`.

## Предварительный просмотр

```bash
sudo hy2-panel import /root/hy2-p.json
```

Без параметров команда только проверяет файл и показывает, какие записи будут добавлены, пропущены или совпадают с существующими. Данные не меняются. То же действие можно указать явно:

```bash
sudo hy2-panel import /root/hy2-p.json --preview
```

В результате смотрите ID экземпляров и причину для каждой записи. Не меняйте ID наугад: они используются для связей пользователей и групп.

## Применение

```bash
sudo hy2-panel import /root/hy2-p.json --apply
```

`--apply` добавляет новые записи. Существующие записи не перезаписываются. Перед применением команда повторно готовит список изменений; если состояние изменилось во время операции, импорт может потребовать повторной проверки.

Не указывайте `--preview` и `--apply` одновременно: текущий скрипт использует последний из них.

## Связать экземпляры

```bash
sudo hy2-panel import /root/hy2-p.json --map-core default=default --preview
```

`--map-core ИСТОЧНИК=ЦЕЛЬ` связывает ID из файла с существующим ID на этой панели. Новая копия этого экземпляра не создаётся, его конфигурация не заменяется. Пользователи и группы получают связь с выбранной целью. `default` означает основной экземпляр.

Параметр можно повторять для разных экземпляров. После проверки замените `--preview` на `--apply`.

## Исключить экземпляр

```bash
sudo hy2-panel import /root/hy2-p.json --skip-core ID_ИЗ_ФАЙЛА --preview
```

`--skip-core ID` исключает экземпляр из импорта и удаляет связь с ним из импортируемых правил доступа. Остальные данные продолжают обрабатываться. Если исключены все доступные экземпляры пользователя, он добавляется без доступных подключений.

Повторите параметр, чтобы исключить несколько экземпляров. Проверьте результат и выполните ту же команду с `--apply`.

## Через браузер

Откройте **Настройки → Импорт и экспорт**. Нажмите **Экспортировать** для скачивания JSON. Для импорта перетащите JSON в область загрузки, проверьте совпадения и для каждого экземпляра выберите создание, связь с существующим или исключение. Затем нажмите **Добавить**.

Обычный YAML не содержит пользователей HY2-P. Он импортируется отдельно в **Конфигурации**, изменяет черновик выбранного экземпляра и применяется только после сохранения и перезапуска.

Экспорт JSON не заменяет [резервную копию](../operations/backups.md): для восстановления сертификатов, ключей и всей установки нужна полная копия.
