# Mimic

Mimic маскирует UDP-пакеты под TCP. Он нужен на обеих сторонах соединения и работает только в Linux. Обычные приложения на iOS, Android и Windows к такому экземпляру не подключатся. Не включайте его для пользователей с такими клиентами.

## Подготовка

- Linux 6.1 или новее с поддержкой eBPF и BTF.
- Hysteria2 2.13.0 или новее на сервере и Linux-клиенте.
- Модуль `mimic` для текущего Linux.
- TCP и UDP на публичном порту экземпляра, разрешённые в firewall сервера и хостинга.

Для Docker режим назначается одному экземпляру. Остальные экземпляры продолжают использовать обычный UDP. Панель и экземпляры в этом контейнере запускаются от root с `DAC_OVERRIDE`, `NET_ADMIN`, `NET_RAW`, `BPF`, `PERFMON`. Сеть остаётся изолированной; `privileged`, сеть хоста и `SYS_ADMIN` не используются.

## Установка

1. В **Экземплярах** создайте отдельный экземпляр для Mimic и примените его UDP-порт.
2. Откройте **Конфигурация → Mimic**. В блоке установки выберите **Экземпляр для Mimic** и скопируйте полученную команду. Выбор переключает конфигурацию и проверки на этот экземпляр; раздел Mimic остаётся открытым. Сама установка выполняется на сервере.
3. Выполните команду на сервере и подтвердите изменение режима:

```bash
sudo hy2-panel mimic-setup --instance ID_ЭКЗЕМПЛЯРА
```

Для основного экземпляра ID равен `default`. Предварительный просмотр:

```bash
sudo hy2-panel mimic-setup --instance default --dry-run
```

Установщик проверяет версию Linux и опубликованные порты, устанавливает официальный пакет `mimic-dkms` с проверкой SHA256, загружает модуль и настраивает его загрузку после перезагрузки. Автоустановка пакета поддерживает Ubuntu 24.04, 26.04 и 26.10 на AMD64 и ARM64. Уже установленный модуль используется без повторной установки. Linux автоматически не обновляется.

Для другой ОС подготовьте модуль по [официальной инструкции Mimic](https://github.com/hack3ric/mimic/blob/master/docs/building.md), затем повторите команду. Secure Boot или ограничения VPS могут препятствовать загрузке модуля. При ошибке установки права контейнера не меняются; при неудачном запуске возвращаются прежние параметры.

## Параметры `mimic-setup`

- `--instance ID`: экземпляр для Mimic. По умолчанию `default`, основной. ID дополнительного экземпляра состоит из 16 шестнадцатеричных символов; скопируйте готовую команду из панели. Название вместо ID не принимается.
- `--dry-run`: выводит план без установки, загрузки модуля и перезапуска. Это просмотр действий, а не полная проверка готовности системы.
- `--yes`: выполняет выбранное действие без вопроса подтверждения.
- `--disable`: отключает режим установки Mimic, возвращает обычные права контейнера и убирает дополнительную публикацию TCP. Пакет модуля сохраняется. Можно сочетать с `--dry-run` или `--yes`.

`mimic-setup` готовит установку, но сам не включает `mimic.enabled` в конфигурации.

## Настройка в панели

1. В **Управление HY2** обновите экземпляр до версии с поддержкой Mimic.
2. В **Конфигурация → Mimic** нажмите **Проверить**.
3. Включите `mimic.enabled`. `mimic.interface` обычно можно оставить пустым. В Docker это интерфейс контейнера, обычно `eth0`, а не интерфейс Ubuntu.
4. `mimic.xdpMode` оставьте по умолчанию. При несовместимости драйвера попробуйте `skb`.
5. `mimic.path` оставьте пустым: в образе уже есть `/usr/local/bin/mimic`.
6. При необходимости добавьте `mimic.extraArgs`, по одному аргументу на строку, например `--padding=random`.
7. Сохраните конфигурацию и перезапустите экземпляр. Проверьте журнал.

На Linux-клиенте также установите Mimic и его модуль, затем включите `mimic.enabled` в конфигурации Hysteria2. Обычной подписки недостаточно для установки модуля на устройстве пользователя.

Проверка готовности подтверждает наличие программы, модуля и прав. Проверить доступность через сеть оператора можно только реальным подключением клиента. Port hopping с Mimic не поддерживается.

## Отключение

Сначала выключите `mimic.enabled` и сохраните конфигурацию, затем выполните:

```bash
sudo hy2-panel mimic-setup --disable
```

Панель вернётся к обычному пользователю контейнера и удалит дополнительную публикацию TCP-порта. Установленный системный пакет модуля сохраняется. Перед откатом панели на версию без поддержки Mimic отключите этот режим.

Для удаления установки Mimic:

```bash
sudo hy2-panel mimic-uninstall
```

`mimic-uninstall` принимает только необязательный `--yes` для удаления без вопроса. Режима `--dry-run` у этой команды нет. В вопросах Mimic принимаются `yes` и `y` без учёта регистра, любой другой ответ отменяет действие.

Команда запросит подтверждение, отключит режим, удалит настройки и установленный панелью пакет модуля. Если модуль используется другим процессом или от пакета зависят другие программы, он сохранится с пояснением в выводе. Ранее установленный сторонний модуль не удаляется.
