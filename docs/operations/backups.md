# Резервные копии

## Создать копию

```bash
sudo hy2-panel backup
```

Команда временно останавливает панель и все её экземпляры HY2, чтобы данные и ключи не менялись во время копирования. Если панель работала, после копирования она запускается снова. Если была остановлена, остановленной и остаётся.

В конце выводится путь вида `/opt/hy2-panel/backups/20261112T120000Z.ABCDEF`. Время в имени указано в UTC. Команда не принимает имя файла или путь назначения.

## Что хранится в копии

- `data.tar.gz`: содержимое рабочего Docker-тома, включая пользователей, конфигурации, ключи и сохранённую статистику.
- `certs.tar.gz`: каталог внешних сертификатов `/opt/hy2-panel/certs`.
- `environment`: параметры `.env`.
- `extra-udp.json`: публикация портов дополнительных экземпляров.
- `manifest.json`: формат копии, время и коммит панели.

Копия содержит секреты. Каталог доступен только root, файлы создаются с правами `600`. Docker-образ и исходники версии в неё не входят. Образ для отката хранится [отдельно](storage.md).

## Забрать копию с сервера

Сначала на сервере создайте копию и запомните выведенный путь. Если SSH разрешён для root, выполните на своём компьютере, подставив настоящий IP и имя каталога:

```bash
scp -r root@203.0.113.10:/opt/hy2-panel/backups/20261112T120000Z.ABCDEF .
```

При входе другим пользователем потребуется дать ему доступ к копии или забрать её через средство передачи файлов с правами sudo. Не делайте каталог копий общедоступным.

Копия на том же VPS не защищает от потери сервера. Храните ещё одну вне него. Перед [удалением панели](../uninstall.md) вынесите нужную копию за пределы каталога установки: он удаляется вместе с бэкапами.

## Восстановление

`rollback` автоматически выбирает копию перед последним обновлением и возвращает соответствующую версию. [Порядок отката](updates.md#откатить-панель).

Команды `hy2-panel restore` и выбора произвольной копии в CLI нет. Не распаковывайте архив поверх работающей панели: версия, данные, ключи, сертификаты и порты Docker должны соответствовать одной копии.

Для переноса пользователей и конфигураций на другую работающую панель используйте [экспорт и импорт JSON](../management/transfer.md). Это перенос выбранных данных, а не полное восстановление резервной копии.

## Где что хранится

Для стандартной установки:

- `/opt/hy2-panel/.env`: начальные параметры запуска и первого входа.
- `/opt/hy2-panel/current`: коммит работающей версии.
- `/opt/hy2-panel/previous`: коммит предыдущей версии, если доступен откат.
- `/opt/hy2-panel/rollback-backup`: путь копии для отката.
- `/opt/hy2-panel/releases`: исходники загруженных версий.
- `/opt/hy2-panel/backups`: резервные копии данных.
- `/opt/hy2-panel/image-archives`: сжатые образы для отката.
- `/opt/hy2-panel/certs`: внешние сертификаты панели.
- `/opt/hy2-panel/cloud-backup`: закрытые настройки облачных хранилищ и приложений авторизации; в обычную копию не входят.
- Docker-том `hy2-panel_panel-data`: рабочие данные, включая ключи шифрования.

При `--directory` пути начинаются с выбранного каталога. Имя Docker-тома не меняется. Файлы `update.pending` и `udp.pending` описывают незавершённые операции; не удаляйте их для обхода ошибки.
