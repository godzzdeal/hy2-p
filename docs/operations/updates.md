# Обновление и откат

## Обновить панель

```bash
sudo hy2-panel update
```

Без аргумента выбирается `latest`, последний релиз GitHub. То же самое с явным указанием версии:

```bash
sudo hy2-panel update latest
```

Для конкретного релиза укажите его точный git-тег:

```bash
sudo hy2-panel update v0.9.2
```

Допускаются также `main` и полный 40-символьный хеш коммита. Для них без готового образа нужна [сборка из исходников](../installation/environment.md#hy2_build_from_source). `update` не принимает `--yes`, `--domain`, `--port` или параметры установщика.

До переключения версии панель продолжает работать. Скрипт загружает образ, проверяет контрольную сумму, архитектуру и коммит. Затем останавливает панель, создаёт копию данных и сертификатов, запускает новую версию и ждёт проверки её состояния. VPN-подключения при переключении прерываются.

Если первый запуск не прошёл проверку, скрипт возвращает предыдущую версию и данные. При успешном автоматическом возврате команда завершается с кодом `10`: обновление не установлено, хотя прежняя панель снова работает. Если восстановление тоже завершилось ошибкой, копия и журнал операции остаются для диагностики.

Если выбрана уже установленная версия, повторная установка не выполняется. После обновления проверьте:

```bash
sudo hy2-panel status
sudo hy2-panel url
```

Для старой установки без команды `update` повторно запустите актуальный установщик с прежним каталогом установки. Он обнаружит существующую панель и запустит обновление.

## Откатить панель

```bash
sudo hy2-panel rollback
```

Команда показывает путь копии и ждёт точного ответа `yes`. Ответ `y` эта команда сейчас не принимает. Для запуска без вопроса:

```bash
sudo hy2-panel rollback --yes
```

Откат возвращает **предыдущую версию и данные на момент копии перед обновлением**. Новые пользователи, пароли, конфигурации и изменения трафика после этой копии не восстановятся. Перед откатом скрипт сохраняет ещё одну копию текущих данных.

Если предыдущий образ уже сжат, он загружается из локального архива с проверкой целостности. Скачивать его повторно не требуется. Нужны место для распаковки образа и сохранённые файлы предыдущей версии.

После успешного отката указатель предыдущей версии очищается. Повторить откат на версию, с которой вы вернулись, этой командой нельзя. Копия состояния до отката остаётся на диске; отдельной команды восстановления произвольной копии пока нет.

## Обновить из браузера

В **Настройки → Обслуживание** проверьте версии, выберите нужную и нажмите **Обновить**. После перезапуска панель проверит результат. Здесь же доступны откат и перезапуск панели. Нужна установка через скрипт с помощником обслуживания.

Перезапуск панели из этого раздела влияет на все экземпляры HY2. Перезапуск одного экземпляра выполняется в **Управление HY2**.

## Обновить HY2

В **Управление HY2** выберите экземпляр и версию HY2. Если версия уже установлена, повторная установка не нужна. При смене версии перезапускается выбранный экземпляр, а не вся панель. Watchdog проверяет его работу после обновления, пытается перезапустить при сбое и возвращает прежнюю версию, если запуск не восстановился.

Версия панели и версия HY2 независимы. `hy2-panel update` обновляет панель; версию каждого процесса HY2 выбирают отдельно.
