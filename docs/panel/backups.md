# Резервные копии

В **Настройки панели → Резервные копии** нажмите **Создать бэкап**. Копия включает данные панели, пользователей, конфигурации, ключи, сертификаты и настройки установки. Во время создания панель и подключения кратковременно перезапускаются.

Копии сохраняются на сервере в `/opt/hy2-panel/backups`. Результат задачи показывается в уведомлении. Через терминал:

```bash
sudo hy2-panel backup
```

## Облачное хранилище

Поддерживаются Яндекс Диск, Google Drive и другие хранилища rclone.

1. [Установите rclone](https://rclone.org/install/) на свой компьютер.
2. Выполните `rclone config`, создайте подключение, например `disk`, и разрешите доступ к выбранному диску в браузере. Для Google Drive выберите область доступа `drive.file`, если планируете хранить только созданные rclone файлы.
3. Команда `rclone config file` покажет путь к конфигурации. Загрузите этот `.conf` в разделе резервных копий панели.
4. Укажите папку, например `disk:HY2-P`, и нажмите **Сохранить**.
5. Нажмите **Отправить в облако**. Панель создаст свежую локальную копию, загрузит архив и скачает его для проверки содержимого.

В имени архива указаны сервер, время UTC и отпечаток. Локальная копия сохраняется при успешной отправке и при ошибке. Файлы, уже находящиеся на диске, не удаляются. Восстановление из облака пока выполняется вручную: скачайте архив и распакуйте его; внутри находятся данные, сертификаты и параметры установки.

Подключение хранится на сервере с закрытыми правами доступа. Пароли и OAuth-токены не возвращаются в браузер. Сам архив содержит секреты сервера: используйте закрытую папку облачного диска. Для шифрования на стороне клиента настройте [rclone crypt](https://rclone.org/crypt/) и укажите его подключение.

При первой отправке загружается официальный образ rclone; для обычных локальных копий он не нужен. Для работы нужны исходящие HTTPS-соединения сервера с облаком и реестром образов. Расписание отправки пока не настроено: каждая отправка запускается вручную.

Через терминал после подключения хранилища в панели:

```bash
sudo hy2-panel backup-cloud
```
