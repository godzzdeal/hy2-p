# Экземпляры и конфигурации

Панель поддерживает до 8 экземпляров HY2. У каждого свой процесс, конфигурация, порт, версия и журнал. Для пользователей панели трафик и ограничения общие.

## Создать экземпляр

В **Экземплярах** нажмите **Добавить**. Укажите название и исходный экземпляр для копирования настроек. Новый экземпляр останется остановленным.

Откройте его **Конфигурацию**, проверьте адрес, `listen`, публичный UDP-порт, сертификаты и режим аутентификации. Каждому экземпляру нужен свободный порт. Сохраните настройки и примените публикацию порта, затем запустите экземпляр.

Публикация Docker пересоздаёт общий контейнер панели и кратковременно прерывает все подключения. Обычный запуск, остановка, перезапуск и обновление версии HY2 затрагивают только выбранный экземпляр.

## Изменить конфигурацию

В **Конфигурации** выберите раздел либо найдите свойство по имени из документации Hysteria2. Кнопка информации рядом с именем объясняет поле. Кнопка сброса удаляет явно заданное значение, чтобы использовать значение по умолчанию.

Для полного YAML нажмите **Открыть**. Редактор проверяет синтаксис; **Упорядочить** располагает известные поля в порядке документации. Неизвестные свойства и комментарии сохраняются.

Изменения остаются в черновике до сохранения. Сохранение не перезапускает процесс. Для применения перезапустите выбранный экземпляр. Если меняли публичный порт или `listen`, примените также публикацию Docker.

Обычный YAML можно загрузить файлом. Он заменяет черновик выбранного экземпляра и не добавляет пользователей панели. Для переноса пользователей и групп нужен JSON HY2-P из **Настройки → Импорт и экспорт**.

## ACL

В **Конфигурация → ACL** добавьте правило. Отдельная форма задаёт исходящее подключение, адрес, протокол и порты; результат виден перед сохранением. Нажатие на правило открывает его форму. В меню строки можно переместить правило или удалить его.

Порядок важен: используется первое совпадение. Комментарии и строки, которые редактор не распознал, сохраняются. Для неизвестного синтаксиса проверьте результат в YAML перед запуском.

`acl.file` подключает текстовый файл правил; при его использовании встроенный список `acl.inline` не действует. Для `acl.file`, `acl.geoip` и `acl.geosite` доступны путь, загрузка с компьютера и скачивание по HTTPS. Панель сохраняет файл локально и записывает путь в конфигурацию. Это не автоматически обновляемая подписка на URL.

Лимит текстовых правил 1 МБ, GeoIP и GeoSite 128 МБ. Загружайте базы в формате `.dat`. При переносе конфигурации на другой сервер подготовьте файлы заново.

## Сертификаты и ECH

В **TLS / ACME** выберите свой сертификат с ключом либо ACME. Загруженные пары проверяются перед сохранением. Список ниже показывает найденные сертификаты и сроки действия.

Удаление сертификата требует подтверждения и удаляет связанный ключ. Файлы, используемые работающими экземплярами, защищены. Для ACME сертификат может быть выпущен снова после запуска.

ECH настраивается отдельно от TLS-сертификата: создайте ключ, проверьте `ech.keyPath`, сохраните и перезапустите экземпляр. Клиенту передаётся публичная часть. После замены ключа обновите подписку. [Пример настройки](../configuration.md).

`pinSHA256` относится к клиентскому подключению. В параметрах подключения можно вычислять его по сертификату. После замены сертификата клиент должен получить новый отпечаток.

## Управление HY2

Раздел показывает состояние выбранного процесса, запуск, остановку, перезапуск и версии. Выберите другую версию для обновления; уже установленную повторно устанавливать не нужно. [Обновление и откат](../operations/updates.md#обновить-hy2).

Журнал можно искать по тексту, уровню и пользователю. Расшифровка ID клиента появляется, если панель может связать его с пользователем или устройством. Автопрокрутка включает переход к новым сообщениям; выключите её для чтения старых. Скачивание сохраняет журнал в файл, очистка удаляет текущие записи из журнала панели.

## Удалить экземпляр

Нажмите удаление на его карточке и подтвердите. Панель остановит процесс, удалит конфигурацию и публикацию дополнительного порта. Пользователи сохранятся, но подключение к удалённому экземпляру исчезнет. Если публикация порта не удалена из-за ошибки, устраните причину и повторите удаление.
