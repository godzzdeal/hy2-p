# Настройки панели

Разделы раскрываются по заголовку. Настройки веб-панели относятся ко всей установке, конфигурации HY2 относятся к выбранному экземпляру.

## Учётная запись администратора

Изменяет логин и основной пароль администратора. Для смены только логина оставьте новый пароль пустым. Требуется текущий пароль. После сохранения все сеансы завершаются. [Если пароль забыт](../management/recovery.md).

## Облачный пароль

Дополнительный пароль после основного при каждом входе. Для включения или замены задайте основной пароль, новый дополнительный пароль и его подтверждение. Для отключения подтвердите действие требуемыми паролями. Это защита входа в панель, VPN-пользователи её не вводят.

## Импорт и экспорт

Переносит конфигурации экземпляров, пользователей, группы и лимиты через JSON. Сначала показывает план и совпадения, затем добавляет новые записи. [Состав файла и команды](../management/transfer.md).

## Настройки панели

- **Адрес веб-панели** выбирает, доступна ли панель только локально или на сетевых интерфейсах сервера.
- **Порт веб-панели** задаёт TCP-порт веб-интерфейса, отдельно от UDP-портов HY2.
- **Публичный URL панели и подписок** формируется автоматически из домена или IP, протокола и порта, например `https://panel.example.com:9443`.
- **HTTP** работает без сертификата. За reverse proxy HTTPS может завершаться на прокси; прямой HTTP не шифруется.
- **Собственный TLS-сертификат** использует загруженную пару сертификат/ключ, подходящую указанному адресу.
- **ACME** выпускает сертификат автоматически. Укажите домен или публичный IP, email, примите условия центра сертификации и обеспечьте доступность проверки.

После сохранения параметров, требующих перезапуска, подтвердите перезапуск панели. Вход и VPN-подключения прервутся. Откройте новый адрес с правильным портом. При ручном Docker Compose публикацию порта меняют отдельно.

Домен веб-панели и адреса VPN можно изменить независимо. Автоматически подставленное значение при первоначальной настройке не запрещает указать отдельный адрес экземпляру.

HTTPS веб-панели не настраивает сертификаты HY2. Для них используйте **Конфигурация → TLS / ACME**.

## Firewall

Показывает UFW и рекомендации портов на основе настроек. Для изменения правил подключите помощник командой `firewall-setup`. [Подключение, порты и отмена правил](../management/firewall.md).

## Обслуживание

Здесь можно перезапустить панель, выбрать её версию, обновить, откатить и очистить старые образы. Для операций Docker нужен помощник управляемой установки. Перед обновлением создаётся копия; откат возвращает её данные вместе с версией. [Порядок обновления](../operations/updates.md).

Проверка релиза в нижней панели только получает информацию с GitHub. Она не устанавливает обновление без выбранного действия.
