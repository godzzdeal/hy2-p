# Пользователи, группы и подписка

## Создать пользователя

В **Пользователях** нажмите **Добавить**, задайте имя и пароль. Пароль можно сгенерировать. При необходимости выберите флаг и срок доступа. Эмодзи добавляются прямо в имя.

Новый пользователь получает доступ через аутентификацию панели. Если экземпляр использует собственные настройки `auth`, доступ к нему определяется его YAML, а не списком пользователей HY2-P.

В меню пользователя откройте **Подключение**. Скопируйте адрес подписки либо откройте и отсканируйте QR-код в приложении с поддержкой Hysteria2. Подписка содержит разрешённые пользователю опубликованные экземпляры. Отдельная ссылка `hy2://` содержит только одно подключение и не обновляется сама.

## Выбрать экземпляры

Откройте **Доступные экземпляры** в меню пользователя. Выберите все, включая будущие, или только отмеченные. Без выбранных экземпляров пользователь не сможет подключаться.

При снятии доступа текущее подключение к этому экземпляру отключается. После изменения списка попросите пользователя обновить подписку в приложении.

## Трафик

В меню пользователя откройте **Трафик**. Здесь можно изменить лимит, единицу измерения и счётчики отправленных и полученных данных. `0` в лимите означает отсутствие личного ограничения. Лимит группы, если он задан, продолжает действовать.

Счётчики общие для доступных пользователю экземпляров. После исчерпания квоты доступ блокируется. Увеличьте лимит или сбросьте счётчики, чтобы разрешить подключение. Если меняете только лимит, счётчики сохраняются.

Цветной квадрат в списке показывает состояние подключения по последним данным статистики. Это состояние соединения, а не проверка доступности физического устройства.

## Устройства

Откройте **Устройства** в меню пользователя. Лимит `0` снимает ограничение на число зарегистрированных устройств. При включении лимита пользователь должен обновить подписку в приложении с передачей идентификатора устройства; этот режим проверен с Happ.

После включения лимита старые одиночные ссылки с общим паролем не работают. В списке отображаются сведения, переданные приложением: модель, ОС, версия, IP и время обращения. Панель не определяет физическое устройство самостоятельно.

Отключение устройства отзывает его ключ. Удаление записи тоже отзывает ключ, но при следующем обновлении подписки устройство сможет зарегистрироваться заново, если лимит это допускает.

## Группы

Нажмите **Группы**, создайте группу и задайте её ограничения: лимит трафика и устройств на участника, доступные экземпляры. Пользователь может входить только в одну группу.

Кнопка **Участники** открывает список для массового назначения. Найдите пользователей, отметьте нужных и сохраните. Пользователи из других групп переместятся в выбранную; снятие отметки уберёт пользователя из этой группы. Запись пользователя и счётчики сохраняются.

Групповой лимит применяется к каждому участнику, а не делится на всю группу. При личном и групповом ограничении действует более строгий лимит. Пользователь получит доступ только к экземплярам, разрешённым и ему, и группе. Фильтр над списком показывает выбранную группу; заголовки групп можно сворачивать.

## Подписка

В разделе **Подписка** задайте название и эмодзи. Название появится в приложении после обновления подписки; его максимальная длина 25 символов.

Общий флаг применяется к пользователям без индивидуального флага. Он не меняет имена. Собственный флаг пользователя имеет приоритет. Приложение само решает, как отображать переданные имя и иконку.

Период обновления передаётся приложению как рекомендация. Фактическое фоновое обновление зависит от приложения и ОС. Нажатие **Сохранить** не обновляет подписки на устройствах.

Для сообщения о технических работах включите объявление и сохраните текст. Его покажут приложения с поддержкой объявлений после обновления подписки. Это не push-рассылка. При отключении объявления и следующем обновлении оно исчезнет.

## Маршрутизация клиентов

В разделе **Подписка → Маршрутизация клиентов** включите **Выбранные сайты напрямую, остальные через VPN**. Перечислите домены по одному в строке, например `example.com`. Протокол и путь не нужны; поддомены включаются автоматически. Можно добавить до 64 доменов, общий размер списка ограничен для передачи в заголовке подписки.

Сохраните настройки. Пользователям нужно обновить подписку и переподключиться. Список общий для пользователей панели. При выключении настройки подписка передаёт команду отключения ранее настроенного профиля.

Этот формат поддерживает **Happ**. Другие приложения могут проигнорировать правила: обычные ссылки `hy2://` продолжают передаваться как прежде. При добавлении одиночной ссылки правила не передаются. Поддержка и формат описаны в [документации Happ](https://docs.happ.info/main/dev-docs/routing).

Указанные сайты выходят в интернет непосредственно с устройства, остальные через VPN. Это отдельная настройка клиента; серверный ACL не меняется. Один сайт может использовать несколько доменов для входа, изображений и видео: при необходимости добавьте их тоже.
## Поиск и обновление списка

Поиск фильтрует пользователей по имени, фильтр группы оставляет в списке её участников. Кнопка **Обновить** запрашивает пользователей, группы и трафик с сервера. Счётчик в заголовке показывает общее число, а результат поиска указан отдельно.
