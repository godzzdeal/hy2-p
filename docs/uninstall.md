# Удаление HY2-P

Полное удаление выполняется на сервере через SSH:

```bash
sudo hy2-panel uninstall
```

Команда покажет список ресурсов и запросит подтверждение `yes` или `y`. Ответ `no`, `n` или пустая строка отменит удаление.

Будут удалены:

- Контейнеры панели, веб-интерфейса, помощника и завершённых операций обновления.
- Пользователи, конфигурации всех экземпляров, ключи и сертификаты.
- Резервные копии, скачанные версии и сжатые образы для отката.
- Тома, сети и неиспользуемые образы Docker этой установки.
- Установленный помощник Firewall и команда `hy2-panel`.
- Каталог установки, по умолчанию `/opt/hy2-panel`.

**Восстановить удалённые данные нельзя.** Если нужна копия, выполните `sudo hy2-panel backup` и скопируйте полученный каталог за пределы каталога установки.

Проверить список без удаления:

```bash
sudo hy2-panel uninstall --dry-run
```

Для удаления без запроса подтверждения:

```bash
sudo hy2-panel uninstall --yes
```

Docker и другие приложения сохраняются. Общие образы и сети, используемые другими контейнерами, остаются. Если данные панели подключены к стороннему контейнеру, удаление остановится до внесения изменений.

Правила UFW сохраняются: через панель можно управлять портами всего сервера. Удаление панели не сбрасывает защиту SSH и других сервисов. Отдельно созданные копии и файлы за пределами установки также сохраняются.

Если использовался Mimic, файл автоматической загрузки модуля этой установки удаляется. Системный пакет `mimic-dkms` сохраняется: его могут использовать другие программы.
