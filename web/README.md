# Веб-интерфейс HY2-P

React, TypeScript, Bun и Rspack. Стили используют CSS, SCSS и Tailwind CSS. Состояние API хранится в TanStack Query, состояние интерфейса — в Zustand.

## Структура

- `src/app` — запуск интерфейса и выбор экрана входа.
- `src/pages` — страницы, которые собирают компоненты раздела.
- `src/components` — интерфейс. Общие элементы находятся в `ui` и `elements`, навигация — в `layout`, остальные компоненты сгруппированы по разделам панели.
- `src/services` — HTTP-клиент, запросы и контракты API. Здесь нет React и состояния интерфейса.
- `src/hooks` — загрузка данных, изменения, обновление кеша и взаимодействие с браузером.
- `src/store` — выбранное ядро, тема, навигация и незавершённая операция применения порта.
- `src/providers` — подключение контекста TanStack Query.
- `src/config` — маршруты, параметры кеша, переводы и схема свойств Hysteria2.
- `src/utils` — обработка YAML, эмодзи, дат и другие независимые функции.
- `src/styles` — темы и оформление.

Компонент вызывает хук, хук обращается к сервису. Сервис не импортирует компоненты, хуки или хранилища. Импорты внутри приложения используют `@/`.

Запросы к конкретному ядру проходят через `instanceRoute`; их ключи кеша — через `instanceKey`. При изменении выбранного ядра данные других ядер не должны попадать на его экран. Секреты ECH, Traffic Stats и загрузки сертификатов не сохраняются в долговременном кеше мутаций.

## Проверки

Из каталога `web`:

```bash
bun install --frozen-lockfile
bun run lint
bun run test
bun run build
bun run test:ui
```

Проверки интерфейса используют собранный `dist` и подменяют API. Сервер разработки для них не нужен. Проверка настоящих серверных маршрутов и Docker-установки выполняется отдельно в CI.

`bun run dev` запускает режим разработки.
